## Problem

Build times are frustratingly slow, even for simple linting/checking operations. This significantly impacts developer experience.

## Investigation Needed

1. Profile `cargo build` / `cargo clippy` / `cargo check` to identify bottlenecks
2. Check if incremental compilation is working properly
3. Identify which dependencies are slow to compile
4. Look for unnecessary recompilations
5. Consider using tools like:
   - `cargo build --timings` to see where time is spent
   - `cargo-llvm-lines` to identify bloated generic code
   - `sccache` or `mold` linker for faster builds

## Potential Solutions

- Split workspace into smaller crates to improve incremental compilation
- Use faster linker (mold on Linux, lld on Mac)
- Enable sccache for caching
- Reduce compile-time dependencies (especially proc macros)
- Check if debug builds can be optimized without losing debug info
- Consider feature flags to make certain heavy dependencies optional

## Context

Triggered during simple code change to make mutate command targets optional - even `just lint` is taking an unreasonable amount of time.
