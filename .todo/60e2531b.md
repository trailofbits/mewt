## Objective

Replace the `--cwd` flag with a `--config` flag that points to the config file. The directory where that config file lives should act as the current working directory.

## Behavior Changes

- Remove `--cwd` flag
- Add `--config` flag that accepts a path to the config file
- The directory containing the config file becomes the implicit working directory
- Relative paths in the config (e.g., `./db.sqlite`, `./logs/`, etc.) should be resolved relative to the config file's directory

## Example

```bash
# Old approach
mewt --cwd /path/to/project --config config.toml

# New approach
mewt --config /path/to/project/config.toml
# All relative paths in config.toml are resolved from /path/to/project/
```
