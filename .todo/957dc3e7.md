## Problem

The `mewt mutate` command currently prints every single mutant as it's generated, which becomes jarring and overwhelming when dealing with more than a few dozen mutants. In practice, generating a few thousand mutants is not uncommon, making the output nearly unusable.

## Solution Implemented

### Default Behavior: Per-Target Summaries

Changed the output format to show concise one-line summaries per target:

```
tests/go/examples/hello-world.go: 7 high, 13 medium, 38 low severity mutants
tests/go/examples/simple.go: 1 high, 3 medium, 5 low severity mutants
```

Special case for targets with no mutants:
```
src/types/config.rs: no mutants generated
```

### Verbose Flag for Detailed Output

Added `--verbose` flag to show the old behavior (individual mutants) for debugging:

```bash
mewt mutate tests/go/examples --verbose
```

Output with `--verbose`:
```
 Generating mutants for targets: ["tests/go/examples"]
   Saved mutant: [ER 2945] Lines 5-7: 'if x > 0 {\n x = 2\n }' -> 'panic("mewt")'
   Saved mutant: [CR 2946] Lines 5-7: 'if x > 0 {\n x = 2\n }' -> '/* if x > 0 {\n x = 2\n } */'
   ...
 tests/go/examples/simple.go: 1 high, 3 medium, 5 low severity mutants
```

### Streaming Output

Summaries are printed immediately after each target is processed (streaming), rather than waiting until all targets are done. This provides real-time feedback during long-running operations.

### Implementation Details

1. **Added `--verbose` flag** to `MutateArgs` in `src/core/cli.rs`
2. **Modified `execute_mutate()`** in `src/core/cmds/mutate.rs` to:
   - Count mutants by severity (high/medium/low) for each target
   - Print one summary line per target after generation completes
   - Only show individual mutants if `--verbose` flag is set
   - Use `LanguageEngine::get_severity_by_slug()` to determine mutant severity

### Files Changed

- `src/core/cli.rs` - Added `verbose` flag to MutateArgs
- `src/core/cmds/mutate.rs` - Implemented per-target summaries and verbose mode

### Testing

Manual testing confirmed:
- Default output shows concise per-target summaries
- Summaries stream as each target completes
- `--verbose` flag shows individual mutants
- Severity counts are accurate (high/medium/low)
- "no mutants generated" message shown for empty targets
- All pre-commit checks pass
