## Problem

The `mewt mutate` command currently prints every single mutant as it's generated, which becomes jarring and overwhelming when dealing with more than a few dozen mutants. In practice, generating a few thousand mutants is not uncommon, making the output nearly unusable.

## Expected Behavior

Instead of printing individual mutants, print a concise one-line summary per target:

**Format:**
```
<target_path>: X high, Y medium, Z low severity mutants
```

**Special case for zero mutants:**
```
<target_path>: no mutants generated
```

**Example output:**
```
src/core/runner.rs: 45 high, 23 medium, 12 low severity mutants
src/core/store.rs: 38 high, 19 medium, 8 low severity mutants
src/types/config.rs: no mutants generated
tests/integration.rs: 12 high, 5 medium, 3 low severity mutants
```

## Implementation

1. Modify `execute_mutate` in `src/core/cmds/mutate.rs` to:
   - Collect mutants per target instead of printing each one
   - Count mutants by severity level (high/medium/low) per target
   - Print one summary line per target after generation completes

2. Consider adding a `--verbose` flag that shows the old behavior (all mutants) for debugging

## Files to Change

- `src/core/cmds/mutate.rs` - Main mutate command logic
- Possibly `src/core/cli.rs` - Add `--verbose` flag to MutateArgs

## Related
