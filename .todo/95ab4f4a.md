## Objective

**Simplify the LanguageEngine trait** by removing convenience methods and moving them to LanguageRegistry. The registry should be the primary API, with engines exposing only core functionality.

## Core Insight

The current pattern has convenience methods in BOTH places:
- ❌ `LanguageEngine::get_severity_by_slug(slug)` - convenience method
- ❌ Need to do: `registry.get_engine(lang)?.get_severity_by_slug(slug)`
- ❌ Results in verbose code and duplicated API surface

The better pattern:
- ✅ Remove convenience methods from LanguageEngine trait
- ✅ Add them ONLY on LanguageRegistry
- ✅ Registry internally calls core engine methods (`get_mutations()`)
- ✅ Cleaner API, simpler trait, single point of access

## Original Design Intent vs Reality

**Original intent:** Get engine once, use it multiple times:
```rust
let engine = registry.get_engine(language)?;
let severity = engine.get_severity_by_slug(slug1);
let slugs = engine.get_all_slugs();
// ... more uses
```

**Reality:** One-off lookups from registry:
```rust
// Different parts of code, scattered
let severity = registry.get_engine(lang)?.get_severity_by_slug(slug);
// ... somewhere else ...
let slugs = registry.get_engine(lang)?.get_all_slugs();
```

**Better pattern:** Registry as primary API:
```rust
let severity = registry.get_severity_by_slug(lang, slug); // defaults to Low
let slugs = registry.get_all_slugs(lang); // returns vec, never fails
```

## Methods to Refactor

### 1. `get_severity_by_slug` (HIGH PRIORITY ⭐)

**Current state:**
- Convenience method on `LanguageEngine` trait (default impl)
- Called via verbose `registry.get_engine(lang)?.get_severity_by_slug(slug)?`
- Always followed by `.unwrap_or(Low)` - so why return Option?

**Proposed change:**

**Remove from LanguageEngine trait:**
```rust
// DELETE this from src/core/engine/traits.rs
fn get_severity_by_slug(&self, slug: &str) -> Option<MutationSeverity> {
    self.get_mutations()
        .iter()
        .find(|m| m.slug == slug)
        .map(|m| m.severity.clone())
}
```

**Add to LanguageRegistry (returns default, not Option):**
```rust
// In src/core/registry.rs
impl LanguageRegistry {
    /// Get severity for a mutation slug, defaults to Low if not found
    pub fn get_severity_by_slug(&self, language: &str, slug: &str) -> MutationSeverity {
        self.get_engine(language)
            .and_then(|engine| {
                engine.get_mutations()
                    .iter()
                    .find(|m| m.slug == slug)
                    .map(|m| m.severity.clone())
            })
            .unwrap_or(MutationSeverity::Low)
    }
}
```

**Usage:** ~10+ occurrences to update
- `src/core/runner.rs` - 4+ uses for sorting mutants by severity
- `src/core/cmds/status.rs` - 2 uses for computing severity stats
- `src/core/cmds/mutate.rs` - 1 use for counting by severity

**Before:**
```rust
let severity = registry
    .get_engine(language)
    .unwrap()
    .get_severity_by_slug(&slug)
    .unwrap_or(MutationSeverity::Low);
```

**After:**
```rust
let severity = registry.get_severity_by_slug(language, &slug);
```

### 2. `get_all_slugs` (MEDIUM PRIORITY)

**Current state:**
- Convenience method on `LanguageEngine` trait (default impl)
- Used once in runner.rs for slug validation

**Proposed change:**

**Remove from LanguageEngine trait:**
```rust
// DELETE this from src/core/engine/traits.rs
fn get_all_slugs(&self) -> Vec<String> {
    self.get_mutations()
        .iter()
        .map(|m| m.slug.to_string())
        .collect()
}
```

**Add to LanguageRegistry (returns empty vec on error):**
```rust
// In src/core/registry.rs
impl LanguageRegistry {
    /// Get all mutation slugs for a language
    pub fn get_all_slugs(&self, language: &str) -> Vec<String> {
        self.get_engine(language)
            .map(|engine| {
                engine.get_mutations()
                    .iter()
                    .map(|m| m.slug.to_string())
                    .collect()
            })
            .unwrap_or_default()
    }
}
```

**Usage:** 1 occurrence in runner.rs

**Before:**
```rust
let valid_slugs = self.registry.get_engine(language).unwrap().get_all_slugs();
```

**After:**
```rust
let valid_slugs = self.registry.get_all_slugs(language);
```

### 3. Keep Core Methods on LanguageEngine

These should **remain on the engine** - they're core functionality:
- ✅ `get_mutations()` - Returns the mutation definitions
- ✅ `apply_all_mutations()` - Generates mutants (complex operation)
- ✅ `tree_sitter_language()` - Parser access
- ✅ `name()`, `extensions()` - Basic metadata

## Implementation Steps

### Step 1: Add new registry methods

```rust
// In src/core/registry.rs
impl LanguageRegistry {
    /// Get severity for a mutation slug, defaults to Low if not found
    pub fn get_severity_by_slug(&self, language: &str, slug: &str) -> MutationSeverity {
        self.get_engine(language)
            .and_then(|engine| {
                engine.get_mutations()
                    .iter()
                    .find(|m| m.slug == slug)
                    .map(|m| m.severity.clone())
            })
            .unwrap_or(MutationSeverity::Low)
    }

    /// Get all mutation slugs for a language
    pub fn get_all_slugs(&self, language: &str) -> Vec<String> {
        self.get_engine(language)
            .map(|engine| {
                engine.get_mutations()
                    .iter()
                    .map(|m| m.slug.to_string())
                    .collect()
            })
            .unwrap_or_default()
    }
}
```

### Step 2: Update all callers

Search and replace patterns:
- `rg "get_engine.*get_severity_by_slug" --type rust` → update to use `registry.get_severity_by_slug(lang, slug)`
- `rg "get_engine.*get_all_slugs" --type rust` → update to use `registry.get_all_slugs(lang)`
- Remove all `.unwrap_or(MutationSeverity::Low)` since it's now built-in

Files to update:
- `src/core/runner.rs` - Multiple severity lookups for sorting
- `src/core/cmds/status.rs` - Severity stats computation
- `src/core/cmds/mutate.rs` - Severity counting
- `src/core/cmds/results.rs` - Our recent severity filter work

### Step 3: Remove methods from LanguageEngine trait

```rust
// In src/core/engine/traits.rs
pub trait LanguageEngine: Send + Sync {
    fn name(&self) -> &'static str;
    fn extensions(&self) -> &[&'static str];
    fn tree_sitter_language(&self) -> TsLanguage;
    fn get_mutations(&self) -> &[Mutation];
    fn apply_all_mutations(&self, target: &Target) -> Vec<Mutant>;
    
    // DELETE these convenience methods:
    // fn get_all_slugs(&self) -> Vec<String> { ... }
    // fn get_severity_by_slug(&self, slug: &str) -> Option<MutationSeverity> { ... }
}
```

### Step 4: Run tests

Verify all tests pass - behavior should be identical, just cleaner API.

## Benefits

1. **Simpler LanguageEngine trait** - Fewer methods = easier to implement new languages
2. **Single point of access** - Registry is the API, engines are implementation details
3. **Less boilerplate** - No more `get_engine()?.method().unwrap_or(default)`
4. **Better defaults** - Built-in fallback behavior (Low severity, empty vec)
5. **Consistent with our recent work** - Matches the `get_mutation()` pattern we just added

## Estimated Impact

- **LanguageEngine trait:** Remove 2 convenience methods (~15 lines)
- **LanguageRegistry:** Add 2 methods (~20 lines)
- **Callers:** Simplify ~10-15 call sites
- **Net change:** -10 to -20 lines, much cleaner API
- **Breaking changes:** None for external users (they use registry, not engines directly)

## Key Insight

This isn't about adding parallel getters - it's about **simplifying the engine trait** by moving convenience methods to the registry where they belong. The registry should handle language lookup + method dispatch, making the engine trait simpler to implement.
