## Problem

Currently, the `--mutation-type` filter only accepts a single mutation slug. This is limiting when users want to filter by multiple mutation types at once. For example, to see both Expression Replacements (ER) and Condition Reversals (CR), users would need to run separate commands.

## Current Usage

```bash
# Can only filter by one type at a time
mewt results --mutation-type ER
mewt print mutants --mutation-type CR
```

## Expected Behavior

Rename to `--mutation-types` (plural) and accept a comma-separated list:

```bash
# Filter by multiple mutation types
mewt results --mutation-types ER,CR,BR
mewt print mutants --mutation-types ER,LR

# Still works with single value
mewt results --mutation-types ER
```

## Implementation

1. **CLI Changes** (`src/core/cli.rs`):
   - Rename `mutation_type` to `mutation_types` in `ResultsArgs` and `PrintMutantsArgs`
   - Update help text to indicate CSV format
   - Parse CSV input into `Vec<String>`

2. **Command Layer** (`src/core/cmds/results.rs`, `src/core/cmds/print/mutants.rs`):
   - Update to pass `Vec<String>` instead of `Option<String>`
   - Pass the list to store layer

3. **Store Layer** (`src/core/store.rs`):
   - Update `get_outcomes_filtered` and `get_mutants_filtered` signatures to accept `Option<Vec<String>>`
   - Change SQL query from `m.mutation_slug = ?` to `m.mutation_slug IN (?, ?, ...)`
   - Use query builder to dynamically build IN clause

4. **Filters Structs**:
   - Update `ResultsFilters` in `src/core/cmds/results.rs`
   - Update `MutantsFilters` in `src/core/cmds/print.rs`

## Files to Change

- `src/core/cli.rs` - Rename and change type
- `src/core/cmds/results.rs` - Update ResultsFilters and parsing
- `src/core/cmds/print.rs` - Update MutantsFilters
- `src/core/cmds/print/mutants.rs` - Update function call
- `src/core/store.rs` - Update both filter functions to use IN clause

## Backward Compatibility

This is a breaking change since the flag name changes. Consider adding a deprecated alias `--mutation-type` that warns users to use `--mutation-types`.
